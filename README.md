# DAYRoute

Expo app for planning a day around tasks, locations, commitments, and travel time.

## Setup

```bash
npm install
npx expo start --lan --clear
```

Scan the QR code with Expo Go on a phone connected to the same Wi-Fi network.

If LAN mode has trouble loading on a phone, use:

```bash
npx expo start --tunnel --clear
```

## Development

- Expo SDK: 57
- Main app: `App.js`
- Entry point: `index.js`
- App config: `app.json`
